# 🎓 Kelas Vibe Coding untuk Pemula

> **Status**: Ide | **Tanggal**: 2026-07-06 | **Tags**: #idea #vibe-coding #kelas #pemula

---

## 📌 Konsep

Kelas yang mengajarkan cara **membangun aplikasi/web tanpa perlu jago coding**, cukup dengan:
- Menjelaskan ide ke AI (prompt)
- Review & iterasi hasil AI
- Deploy ke internet

**Tagline**: *"Dari Ide Jadi Aplikasi, Tanpa Ribet Syntax"*

---

## 🎯 Target Peserta

| Karakteristik | Detail |
|---------------|--------|
| **Usia** | 18-35 tahun |
| **Background** | Non-IT / Fresh graduate / Mahasiswa |
| **Motivasi** | Punya ide app tapi gak bisa coding |
| **Skill** | Bisa pakai laptop & internet |
| **Goal** | Bisa build project sederhana dalam 1-2 minggu |

---

## 📚 Outline Kelas (Draft)

### **Module 1: Apa itu Vibe Coding?** ⏱️ 30 menit
- Definisi & kenapa sekarang waktu yang tepat
- Demo: Buat landing page dalam 5 menit
- Mindset shift: Dari "harus bisa syntax" ke "harus bisa jelasin ide"
- Tools overview: Cursor, Bolt, Lovable, Pi, dll

### **Module 2: Seni Prompt Engineering** ⏱️ 1 jam
- Anatomie prompt yang bagus
- Teknik: Role, Context, Task, Format
- Latihan: 10 prompt → 10 hasil berbeda
- Common mistakes & how to fix

### **Module 3: Build Project #1 - Todo App** ⏱️ 2 jam
- Mulai dari nol dengan AI
- Add features: login, database, deploy
- Hands-on coding bersama

### **Module 4: Build Project #2 - Portfolio Website** ⏱️ 2 jam
- Design thinking: apa yang mau ditampilkan?
- Responsive design dengan AI
- Deploy ke Vercel/Netlify

### **Module 5: Build Project #3 - App Sesuai Ide Peserta** ⏱️ 3 jam
- Brainstorming ide
- Breakdown jadi fitur
- Build dengan guidance
- Peer review

### **Module 6: Beyond Vibe Coding** ⏱️ 1 jam
- Kapan perlu belajar coding "beneran"?
- Path: Dari vibe coder → junior developer
- Resources untuk lanjut belajar
