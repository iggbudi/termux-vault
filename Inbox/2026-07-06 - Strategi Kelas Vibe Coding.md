### Tips Demo Live

| ✅ DO | ❌ DON'T |
|-------|----------|
| Pakai project sederhana dulu | Jangan langsung project kompleks |
| Siapkan prompt di notepad | Jangan improvisasi 100% |
| Tunjukkan error & fix | Jangan sembunyikan masalah |
| Interaksi dengan peserta | Jangan monolog 30 menit |
| Ada backup plan (screenshot) | Jangan bergantung 100% live |

## 2. 📖 CASE STUDY

> **Tujuan**: Tunjukkan PROSES, bukan hanya HASIL

### Template Case Study

```markdown
# Case Study: [Nama Project]

## 🎯 Problem
[Apa masalah yang mau diselesaikan?]

## 💭 Ide & Planning
[Gimana cara breakdown ide jadi fitur?]

## 🤖 Vibe Coding Process
[Prompt apa yang dipake? Iterasi berapa kali?]

## 🛠️ Tech Stack
[Kenapa pilih stack ini?]

## 🐛 Challenges & Solutions
[Apa kendalanya? Gimana solve-nya?]

## 📊 Results
[Hasil akhir: fitur, performa, feedback]

## 💡 Learnings
[Apa yang dipelajari?]
```

### Case Study yang Sudah Ada di Vault

#### **Case Study 1: Toko Curhat**
| Aspek | Detail |
|-------|--------|
| **Problem** | Butuh app anonymous curhat yang simpel |
| **Approach** | Zero dependency, Deno + Deno KV |
| **Vibe Coding** | 100% AI-generated dari ide |
| **Result** | App working, deploy, dipake orang |
| **Learning** | Kadang simple > complex |

**Prompt Example**:
```
Buat aplikasi anonymous curhat dengan Deno dan Deno KV. 
Fitur: posting curhat, reply anonymous, like. 
UI minimalis, dark mode. Zero dependency.
```

#### **Case Study 2: SafeSphere**
| Aspek | Detail |
|-------|--------|
| **Problem** | Butuh sistem report bullying yang aman |
| **Approach** | Static frontend + Node.js API + SQLite |
| **Vibe Coding** | AI generate API + frontend terpisah |
| **Result** | App bisa dipake untuk report |
| **Learning** | Social impact project bisa dibangun dengan vibe coding |

---

#### **Case Study 3: Lelangu Bitcoin Chart**
| Aspek | Detail |
|-------|--------|
| **Problem** | Mau pantau harga crypto real-time |
| **Approach** | Vanilla JS + public API Tokocrypto |
| **Vibe Coding** | AI generate chart + data fetch |
| **Result** | Dashboard real-time, tanpa framework |
| **Learning** | Vanilla JS masih powerful untuk project kecil |

#### **Case Study 4: Arisan PKK**
| Aspek | Detail |
|-------|--------|
