## 🎓 Learning Path dengan Pi

### Phase 1: Setup (30 menit)

```bash
# 1. Install Termux (Android) atau Terminal (Mac/Linux)
# 2. Install Node.js
pkg install nodejs

# 3. Install Pi
npm install -g @earendil-works/pi-coding-agent

# 4. Login dengan free provider
pi
/login → Xiaomi MiMo (FREE!)

# 5. Start coding!
pi "Buatkan saya landing page sederhana"
```

### Phase 2: Basic Vibe Coding (Minggu 1)

| Hari | Topik | Pi Command |
|------|-------|------------|
| 1 | Apa itu Pi? | `pi "Jelaskan apa yang bisa kamu lakukan"` |
| 2 | Buat file | `pi "Buat file hello.html dengan pesan selamat datang"` |
| 3 | Edit file | `pi "Ubah warna background jadi biru"` |
| 4 | Buat project | `pi "Buat project todo app sederhana"` |
| 5 | Deploy | `pi "Bantu saya deploy ke Vercel"` |
| 6-7 | Review & practice | Repeat dengan variasi |

### Phase 3: Intermediate (Minggu 2-3)

| Topik | Pi Command |
|-------|------------|
| CRUD App | `pi "Buat app manajemen kontak dengan SQLite"` |
| API | `pi "Buat REST API untuk todo app"` |
| Authentication | `pi "Tambahkan login dengan Google OAuth"` |
| Database | `pi "Buat schema database untuk blog"` |
| Testing | `pi "Buat unit test untuk fungsi ini"` |

### Phase 4: Advanced (Minggu 4+)

| Topik | Pi Command |
|-------|------------|
| Full-stack | `pi "Buat full-stack app dengan Next.js dan Supabase"` |
| AI Integration | `pi "Tambahkan fitur AI chatbot"` |
| PWA | `pi "Ubah app jadi Progressive Web App"` |
| Multi-agent | `pi "Buat sistem multi-agent untuk otomasi"` |
