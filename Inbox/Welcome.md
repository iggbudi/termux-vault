# Welcome to Your Second Brain! 🧠

Ini adalah inbox untuk quick capture. 

## Cara Menggunakan

### 1. Quick Capture
Tulis ide atau catatan cepat di sini:
- Ide untuk project
- Link menarik
- Pertanyaan yang belum dijawab
- Observasi harian

### 2. Process Inbox
Rutin review inbox dan pindahkan ke folder yang tepat:
- Project-related → `Projects/`
- Knowledge → `Knowledge/`
- Daily notes → `Daily/`

### 3. Create Links
Hubungkan notes dengan `[[wikilinks]]` untuk membangun knowledge graph.

## Quick Commands (Termux)

```bash
# Tambah catatan cepat
echo "- Ide baru" >> ~/vault/Inbox/$(date +%Y-%m-%d).md

# Cari di vault
rg "keyword" ~/vault/

# Lihat struktur vault
tree ~/vault/ -L 2
```
